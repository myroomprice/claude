Set up

Get MyRoomPrice in five minutes

MyRoomPrice is a skill for Claude in Chrome. Add Claude to Chrome, add MyRoomPrice to Claude, then start a check from any tab.

  1. 1

    Get Claude

    MyRoomPrice runs inside Claude, so you need a Claude account on a paid plan that includes Claude in Chrome. Sign up or upgrade at claude.ai.

    Already use Claude in Chrome? Skip to step 3.

  2. 2

    Add Claude to Chrome

    Open Claude in the Chrome Web Store and click Add to Chrome.

    Then pin it so it's easy to find: click the puzzle-piece icon at the top right of Chrome, and the pin next to Claude. Click the Claude icon and sign in with your Claude account.

  3. 3

    Add MyRoomPrice to Claude

    Go to claude.ai → Customize → Plugins. Click Add, then Add marketplace.

    Choose Add from a repository.

    Type myroomprice/claude, pick Use "myroomprice/claude", leave Sync automatically on so you get updates, and click Sync.

    MyRoomPrice then appears among your plugins. If it isn't switched on, click + to install it.

  4. 4

    Open Claude and type /myroomprice

    On any page in Chrome, click the Claude icon to open the side panel. Start a new chat and type /myroomprice.

  5. 5

    Fill in your stay

    MyRoomPrice opens in the tab you were on, ready for you. Fill in the hotel, its city and country, your dates and guests, and click Check prices.

    Claude takes it from there. If a hotel name matches more than one place, it asks you on the page. Prices appear as each one is confirmed, cheapest first, with reviews of the hotel underneath.

"Claude started debugging this browser"

Chrome shows this bar while Claude works in your browser. It's normal for MyRoomPrice, and it goes away when Claude finishes. While a check is running, don't click Cancel and don't close Claude's background tab: either one stops the check.

The fastest settings

Under the box where you type in Claude's side panel, choose Sonnet 5.5 and the Auto permission mode. In Manual mode, Claude stops to ask before each booking site, which makes a check much slower. Start a new chat after updating MyRoomPrice: a chat keeps the version it started with.

Keep the MyRoomPrice tab open

Claude checks the sites in a background tab and updates your MyRoomPrice tab as prices come in. You can carry on in other tabs.

It only looks

Claude never books, signs in, or types your personal or payment details. You choose a price and book it yourself.

Using Claude Code?

Run /plugin marketplace add myroomprice/claude, then /plugin install myroomprice@myroomprice, with Claude in Chrome connected.

All set?

Type /myroomprice in Claude, or open MyRoomPrice and fill in your stay.
